# HuggingFace-NLP

This repository contains my projects and experiments using Hugging Face’s NLP models and libraries. It includes code for fine-tuning, embedding extraction, and applying transformer models for various NLP tasks.

## Overview

Hugging Face has revolutionized NLP with easy-to-use transformer models and tools. This repo captures practical work with those models including:

- Text classification  
- Named Entity Recognition (NER)  
- Embedding extraction for downstream tasks  
- Fine-tuning pre-trained models on custom datasets  
- Experimenting with model architectures and tokenization
